# Komentář k zákonu č. 252/1997 Sb., o zemědělství

Otevřený komentář k zákonu o zemědělství — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; společná zemědělská politika a podpory, evidence zemědělského podnikatele, geneticky modifikované odrůdy, rodinné zemědělské hospodářství, dotace, evidence využití půdy (LPIS), kontroly podmíněnosti, přestupky a sezónní práce.

Konsolidované znění: dokument e-Sbírky `SB-1997-00252_2026-01-01`.
